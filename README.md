# klaaspoort-cron

Roept elk kwartier de mailcontrole van de Studium Huiswerkapp aan
(vrijgavemails en docentenrapporten). De app zelf staat in een privérepo;
deze repo bevat alleen dit klokje omdat GitHub Actions op publieke repos
gratis en onbeperkt is. Het endpoint is beveiligd met een geheim dat als
repository secret is ingesteld.
